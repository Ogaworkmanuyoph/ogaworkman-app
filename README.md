# Ogaworkman Platform
Connecting artisans to clients - a platform for finding and hiring skilled workers.

## What is Ogaworkman?
Ogaworkman helps people find trusted artisans (plumbers, electricians, carpenters, etc.) near them and hire them easily.

## Features (planned)
- Search artisans by skill & location
- Client reviews & ratings
- Chat / Booking system

## Tech Stack
- JavaScript / Node.js
